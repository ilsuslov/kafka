# kafka



Что сделано
1. Поднял кластер из 2 брокеров и ZooKeeper через docker-compose. Два брокера нужны, чтобы работала репликация фактора 2.
2. Создал топик `my-topic` (3 партиции, 2 реплики) через консольную утилиту.
3. Написал приложение на Python с библиотекой `confluent-kafka`. Внутри работают:
   - Продюсер: отправляет сообщения асинхронно.
   - SingleMessageConsumer: читает по 1 сообщению, смещения коммитятся автоматически.
   - BatchMessageConsumer: набирает ~10 сообщений, обрабатывает их и коммитит смещение вручную один раз.
4. Запустил приложение в двух экземплярах через `replicas: 2` в docker-compose.
5. Настроил гарантию доставки At Least Once.

## Как запустить
1. Установить Docker и Docker Compose.
2. В папке с файлами выполнить:
   ```bash
   docker compose up -d
